# Timetable discovery and advertising release

This release preserves the eleven existing journey URLs and adds seven journeys and two departure-city hubs. The main timetable appears before search and source controls on each journey page. Compact rows show the actual boarding point, published departure time, final destination, operator, type and days. Native source disclosures give the depot, route wording and PDF reference. The homepage keeps its existing title and description, with the city directory and passenger help below search. No homepage metadata experiment is scheduled for this release.

## Advertising review and activation

The build serves without ads by default. With verified configuration, the homepage reserves a manual display unit between the departure-city links and Explore routes, which is rendered by the Popular Routes component. Indexable route timetables reserve a unit after the fifth row at six published departures and a second unit after the timetable and related connections at 25. Search, utility pages, 404s and depot connections without published departures have no ad inventory. Current city hubs are directories with shared enquiry links. Individual city hubs and editorial pages can be reviewed for inventory when they have substantive passenger guidance or enquiry content. The online booking guide is future inventory.

The static HTML reserves 288 px for an eligible placement, including room for a 250 px creative and its label. Saved opt-outs and Global Privacy Control hide reservations before the first paint. An unavailable region, a denied choice, or revisiting an already requested placement removes the reservation. No fill, a timeout, and a blocked script remove the creative and label. The slot collapses when still below the viewport and retains its height if it has reached the viewport to protect the visible timetable. Each position can request once per document when it comes near the viewport. The AdSense script is shared across placements. Use responsive display units with a 250 px height and a width capped at 300 px under Google's supported sizing guidance. Confirm the actual account code and turn off mobile ad size optimization for this layout. [Responsive ad sizing](https://support.google.com/adsense/answer/9183363) · [Ad size optimization](https://support.google.com/adsense/answer/9139818)

The Privacy page explains how the site and Google store advertising choices. Visitors in India and other regions outside the EEA, UK and Switzerland can turn ads off or back on there. Visitors using the Google message can reopen it from the same page.

In AdSense, use **Check for updates** for the site. Keep Auto ads off. [Ads.txt](https://support.google.com/adsense/answer/12171612)

India and other regions use first-party browser storage for the choice and allow ads by default. Turning them off from the Privacy page removes ads and pauses new requests in all open tabs. Global Privacy Control keeps ads off and skips the region lookup. [Vercel request headers](https://vercel.com/docs/headers/request-headers)
